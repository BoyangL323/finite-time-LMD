# From source records to reported quantities

1. Identify the spectrum, temperature, initial state, cutoff, requested budget, and time window in [the case index](../DATA/README.md).
2. Read [trajectory_selection.md](trajectory_selection.md) to choose the comparison curve and confirm time-grid and solver status. Keep fixed-trajectory distances distinct from comparisons against the accepted HEOM references.
3. Apply [errors_and_windows.md](errors_and_windows.md) to the paired samples.
4. Apply [ranking.md](ranking.md) to the per-case errors, then compare with the published-basis tables in the corresponding data folders.

The numbered steps use the recorded analysis conventions. The archived data preserve the results obtained with the original production run settings.

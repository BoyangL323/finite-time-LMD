# Data and case index

| Directory              | Contents                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------- |
| [mDA](mDA/README.md)   | Explicit-bath trajectories, oscillator weights, case settings, and result tables used for comparisons.          |
